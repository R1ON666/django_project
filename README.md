# Django Shop



Учебный Django-проект: список товаров, форма добавления, шаблоны, статика.



## Установка и запуск



```bash

git clone https://github.com/R1ON666/django\_project.git

cd django\_project

python -m venv venv

source venv/Scripts/activate     # Windows (Git Bash)

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
